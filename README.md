# Tally

회계프로그램의 매입매출장 엑셀 한 개를 읽어, 선택한 과세기간의 부가가치세 신고 내용을 업종별 집계양식의 틀로 월별·항목별로 펼쳐 보여 주는 로컬 데스크톱 앱입니다. 제품과 계산의 기준은 [TALLY_CANON.md v3.2](TALLY_CANON.md)이며, 이 README는 사용 안내입니다.

앱은 원장에 있는 거래만 업종 틀의 칸에 월별로 채우고, 원장으로 계산할 수 있는 요약(10% 조정, 결제·건별 역산, 납부, 카드매출 세액공제)을 엑셀 수식으로 만듭니다. 추가 불공, 의제매입세액, 공통매입 면세사업분, 경감, 예정 미환급·고지, 매입자 납부특례, 가산세처럼 회계프로그램이 계산하거나 사람이 판단하는 금액은 저장한 엑셀의 녹색 입력 칸에 넣습니다. 의제 공급가액과 택시 업종의 택시 경감세액은 녹색 칸에 수식을 미리 넣어 두며 덮어쓸 수 있습니다. 일반과세자가 대상이며 간이과세자는 지원하지 않습니다.

## 설치와 실행

Python 3.11 이상이 필요합니다.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e .
python app.py
```

원본 파일은 사용자 PC에서만 처리되며 서버 업로드나 외부 API를 사용하지 않습니다.

테스트를 실행하려면 테스트 의존성까지 함께 설치합니다.

```powershell
python -m pip install -e ".[test]"
python -m pytest
```

`data`, `outputs`, `samples`, `.codex-work`는 업체명과 거래 내역이 들어 있어 추적하지 않습니다. 이 저장소는 공개이므로 실제 거래 자료를 커밋하지 않고, 테스트와 문서에도 실제 업체명·거래처명을 쓰지 않습니다.

## 사용 순서

1. `새 업체 설정 추가`에서 업체명과 업종(기본·건설·도소매·음식점·택시)을 고릅니다. 필요하면 고정자산 계정코드, 계정 예외, 불공 후보 키워드, 카드매출 세액공제 대상 여부를 넣습니다.
2. 매입매출장 엑셀을 고르고 `처리 시작`을 누릅니다.
3. 과세기간을 확인합니다. 기본값은 원장의 마지막 거래 월까지 끝난 가장 최근 분기이며, 예정·확정·확정 6개월 중에서 바꿀 수 있습니다. 기간 밖 거래는 집계에서 빠지고 검산에 건수가 표시됩니다.
4. `엑셀 저장`으로 결과를 저장하고, 엑셀의 녹색 칸에 필요한 값을 넣습니다. 차감 납부할 세액까지 수식으로 다시 계산됩니다.

업체 설정은 `app.py`가 있는 앱 폴더의 `data/companies.json`에 저장되며, 앱을 어느 폴더에서 실행해도 같은 파일을 씁니다. 기존 설정을 편집하는 화면은 없으며 같은 업체명으로 다시 저장하면 대체됩니다. 이전 버전 설정 파일은 업종 기본으로 읽고, 146 명칭·담배 키워드·예정미환급·카드공제 금액 값은 무시합니다.

처리 결과는 처리할 때의 파일·업체·업체 설정에 묶입니다. 처리한 뒤 파일이나 업체를 바꾸거나 같은 업체명으로 설정을 다시 저장하면 `재처리 필요`가 표시되고 기간 변경과 저장이 막힙니다. 새 처리를 시작하면 이전 결과를 먼저 지웁니다.

## 지원 입력 형식

`.xlsx` 또는 `.xlsm` 매입매출장을 지원합니다. 원장 헤더는 시트의 첫 30행에 있어야 하며, 파일에 기록된 시트 크기 정보가 없거나 틀려도 실제 셀을 기준으로 읽습니다. 필수 열 제목은 구분, 전표일자, 거래처, 품명, 공급가액, 부가세, 합계, 매입/매출 유형, `Code`, 계정과목, 카드사명, 카드번호입니다. `전자세금` 열이 있으면 값이 `전자`로 시작하는 거래를 전자, 그 밖은 종이로 구분합니다. 번호·사업자번호·신고월·분개유형·부서 같은 다른 열은 읽지 않습니다.

헤더의 공백·줄바꿈은 무시하며, 부가세는 세액, 합계는 합계금액, 매입/매출 유형은 매입매출유형이라는 제목도 허용합니다. 중복된 `Code` 열이 있으면 `계정과목` 왼쪽의 가장 가까운 `Code`를 계정코드로 사용합니다.

전표일자는 Excel 날짜 셀 또는 `YYYY-MM-DD`, `YYYY.MM.DD`, `YYYY/MM/DD` 문자열입니다. 월계·누계·합계 등 집계 행, 반복된 헤더, 제목·공백 행, 이름 없이 금액만 있는 행은 제외합니다. 상세 거래로 보이는 행의 전표일자가 비었거나 잘못되면, 금액 형식이 잘못되면, 필수 열이 모두 있는 원장 시트가 둘 이상이면 시트와 행을 알리고 중단합니다.

## 업종별 집계표 틀

| 업종 | 매입 세금계산서 열 | 카드외 매입 열 | 결제 채널 매출 |
| --- | --- | --- | --- |
| 기본 | 원재료(146·153·156) · 고정 · 기타 | 카과 · 카면 · 현과 · 현면 | 카드 · 현영 · 제로페이 · 현금 · 면세 결제 |
| 건설 | 원재료(도급)(156) · 도급(600번대) · 고정 · 기타 | 카드 · 현영 | 없음(원장에 있으면 추가) |
| 도소매 | 상품(146) · 고정 · 기타 | 카드상품 · 카드기타 · 현영상품 · 현영기타 | 카드 · 현영 · 오픈마켓 · 제로페이 · 현금 · 면세 결제 |
| 음식점 | 음식재료(146) · 고정 · 기타 | 카과 · 카면 · 현과 · 현면 | 카드 · 현영 · 배민 · 요기요 · 쿠팡이츠 · 제로페이 · 현금 |
| 택시 | 기본과 같음 | 기본과 같음 | 기본과 같음 |

택시는 기본과 같은 틀에 요약의 택시 경감세액과 그 배분만 더합니다. 차량 관련 매입을 불공 후보에서 빼려면 업체 설정의 불공 후보 차량 키워드를 비웁니다.

고정은 200번대 계정과 지정한 고정자산 코드이며, 그 밖의 세 자리 계정은 기타입니다. 면세매입은 매입 세금계산서 첫 열과 같은 코드를 첫 열에 두되, 건설은 의제매입세액 공제 대상인 면세 원재료 153을 면세매입 원재료 열에 둡니다. 건설 업체의 계정 예외를 `코드=원재료`로 저장했다면 세금계산서 열 이름이 바뀌었으므로 `코드=원재료(도급)`으로 다시 저장합니다. 계정코드가 없거나 세 자리 숫자가 아니면 미분류로 검산이 실패합니다. 담배는 상품 등 해당 열에 포함합니다. 매출 세금계산서는 계정명별 열과 고정자산 매각(200번대) 열로 나눕니다. 결제 채널은 거래처·품명·카드사명의 키워드로 나눕니다. 틀에 없는 유형의 거래가 원장에 있으면 열이나 블록을 추가해 빠짐없이 표시합니다.

## 결과 엑셀

- `집계표`: 왼쪽에 매입 세금계산서, 면세매입·불공, 카드외 매입, 매출 세금계산서, 결제 채널 매출 블록을 월별(과세기간의 모든 달)로 두고, 오른쪽에 요약과 녹색 입력 칸을 둡니다.
- `전자·종이`: 세금계산서·계산서를 열별로 전자와 종이로 나눈 월별 집계입니다.
- `불공후보`: 접대비 계정과 차량·거래처·사업 무관 키워드에 맞는 매입을 판정 없이 보여 줍니다. 불공으로 볼 금액은 집계표의 추가 불공 칸에 넣습니다.
- `거래상세`: 원본 값과 기간 포함 여부, 집계 블록·열, 후보 근거입니다.
- `미분류`, `검산`: 계정 미분류 거래와 검산 결과입니다.

요약 산식은 다음과 같습니다. `ROUNDDOWN`은 0 방향으로 버리고 `ROUNDUP`은 0에서 멀어지는 방향으로 올립니다.

- 세금계산서 매입·매출 세액은 `ROUNDDOWN(공급가액 합계 × 0.1, 0)`입니다. 고정은 원본 금액을 쓰고 일반은 계에서 고정을 뺍니다.
- 매입계는 세금계산서 계 + 카드외 매입 공제분 + 의제 − 원장 불공 − 추가 불공 − 공통매입 면세사업분입니다. 카드외 매입은 원본 금액을 씁니다. 요약의 매입 행은 신고서 순서대로 카드 다음에 의제가 옵니다.
- 의제 공급가액 칸에는 면세매입 첫 열(원재료·상품·음식재료) 계를 수식으로 미리 넣습니다. 의제 세액은 공제율과 한도가 업체마다 달라 직접 넣습니다.
- 카드외 매출은 결제 채널 과세 계에서 카드매출 면세분 입력을 뺀 합계금액을 `ROUNDUP(÷ 1.1, 0)`으로 한 번 역산합니다. 건별(현금)도 따로 역산합니다.
- 카드공제는 대상 업체만 과세 결제 합계금액의 `ROUNDDOWN(× 13/1000, 0)`을 납부세액 한도로 계산하며, 납부가 0 이하이면 0입니다.
- 택시 업종은 택시 경감세액 칸에 `MAX(0, ROUNDDOWN(납부 × 0.99, 0))`을 미리 넣습니다. 녹색 칸이라 덮어쓸 수 있고, 전자신고세액공제 같은 다른 경감은 경감·공제세액 칸에 넣습니다.
- 차감 납부할 세액은 납부 − 카드공제 − 택시 경감 − 경감 − 예정 미환급 − 예정 고지 − 매입자 납부특례 + 가산세입니다.
- 택시 업종은 요약 아래 `택시 경감 배분`에 납부세액 기준 운수종사자 지급 90%(올림, 90% 이상 보장), 감차 보상 5%, 운수종사자 복지 4%(버림)를 참고로 보여 줍니다. 반올림 방향 때문에 세 금액의 합은 택시 경감세액과 1원 다를 수 있으며, 납부가 0 이하이면 경감과 배분은 0입니다.

앱 화면에는 블록별 기간 합계, 입력 칸을 0으로 둔 요약(미리 넣은 의제 공급가액, 택시 업종의 택시 경감세액과 배분 포함), 검산이 나옵니다. 입력 칸을 반영한 최종 금액은 저장한 엑셀에서 확인합니다.

## 검산

다음 중 하나라도 있으면 검산 완료로 표시하지 않습니다. 검산이 실패해도 확인 후 검토용 엑셀을 저장할 수 있습니다.

- 선택한 과세기간에 상세 거래가 없음.
- 집계할 수 없는 매입·매출 유형.
- 기간 안 원장과 집계표 배치의 건수·공급가액·세액 차이.
- 계정 미분류 거래.

기간 밖 제외 건수, 틀에 없어 기타로 넣은 계정 예외, 틀에 없어 추가한 열·블록, 불공 후보 건수, 합계는 정보로 표시합니다.

## 알려진 제한사항

- 입력 열을 사용자가 직접 연결하는 자유 형식 매핑은 지원하지 않습니다.
- 홈택스, 회계프로그램, 전자신고와 직접 연동하지 않습니다.
- 원장 시트가 여러 개인 통합문서는 지원하지 않습니다.
- 간이과세자 계산, 의제·공통 안분·가산세 계산, 플랫폼 별도 정산, 카드공제 연간 한도는 앱이 하지 않으며 입력 칸을 씁니다.
